# Changelog

What changed in the Hub, newest first. Dates are the day a change went live on entrosana.app.

## 2026-09-11

- Docs rebuilt as a product documentation: sections, search, an «On this page» column, previous and next, callouts, copy buttons on code, and a full API reference.
- Publishing and taking modules back are the owner's step alone; reviewers admit, hold or reject.
- Files: 400 MB per account, 50 MB per file, public or private links, backed up per file.
- Typefaces Glegoo and Inconsolata shipped with the Hub, preloaded, no swap on load.
- Account page with clear buttons instead of quiet lines; uploads ask for a title.
- Atrium registered at atrium.entrosana.com: the coming forum, carrying the development copy of the docs.

## 2026-09-10

- Services rebuilt per account: address, MCP, port and certificate checks, heartbeats with secret addresses, «check now», rotation; the owner sees the machine's own services in the same list.
- The Add-a-service dialog asks who calls whom first; the secret address is shown in the dialog after Add.
- Guidelines page at entrosana.app/guidelines, linked from Contribute and the registration.
- Dormant accounts: a notice after 24 months without sign-in, erasure three months later.
- Privacy statement: schools paragraph, dormant rule, residency wording; both languages republished.
- Hourly sync of console edits to GitHub with a page in the console.
- docs.entrosana.app with the first six pages.
- Three proposed projects on every board: docs in plain language, website translation, working out the requests.

## 2026-09-09

- Sign-in links shortened to 20 minutes; a mail when a new device signs in; a device list with «sign out everywhere»; a fresh link required before erasure.
- Age confirmation at registration.
- Modules with several contributors, points and a report form; the Modules page in three areas.
- Review page for the team; members list; invitations from every profile.

## 2026-09-08

- Accounts with collector and contributor standing, profiles, journal, picture, public pages, search.
- Proposals with confirmation mail, status page and one-step admit and publish.
