What a contribution looks like

Three shapes the Hub takes today. Each one already exists once, so you can copy the form instead of guessing it.

module

A module

Bring the material, the age group, and one sentence on what the learner can do afterwards. Discussion prompts and thinking pauses belong inside the slides, so a teacher can run it without preparation. «Your Value System» is the shape: 9 slides, a 2-page worksheet, two languages.

see the shapeopen › api

An API connector

Connectors and workflow adapters against the platforms schools already use, built by API engineers with an educative approach. Say which routine it takes over, what a correct result looks like, and where the record of each call lands. Responsibility stays with the person, not with the connector.

service, on entrosana.comopen ↗ mcp

An MCP tool

A tool an assistant can call, on one condition: it answers from a source that can be checked, never from memory. The Lehrplan 21 tool is the shape — a local index of be.lehrplan.ch, so a citation can be verified instead of trusted. Bring the repository, the tool description, and what it refuses to answer.

What happens to what you send
  1. It arrivesinfo@entrosana.com, or the form on entrosana.com. Every submission gets an answer.
  2. It is read against what it claimsThe same standard the site holds itself to: does the thing do what it says, and where does it break.
  3. You get a plain yes, no, or not yetWith the reason. «Not yet» names what is missing.
  4. It lands with your name on itYour name stays on your work, and the record of the decision stays checkable afterwards.
What you can ask for in return
  • A review with its reasons written down, that you can argue with
  • Runway: time, machines, or someone who knows the subject
  • Your work carried on under your name, under AGPL-3.0
The rules, short
  • Everything in the Hub is AGPL-3.0. What you send in is published under it too, with your name on it.
  • Students are welcome. If you are at school, bring a teacher or a guardian into the thread — not as a gatekeeper, as a second pair of eyes.
  • Never send us the personal data of children. A module report needs the group, not the names.
  • Disagree with the work, not with the person. That is the whole code of conduct.
