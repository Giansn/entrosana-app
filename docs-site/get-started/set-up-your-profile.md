# Set up your profile

A name is needed before you propose or contribute, because work is published under it. Everything else is optional.

## Fields

| Field | Where it shows | Limit |
|---|---|---|
| Name | everywhere your work appears | 2 to 120 characters |
| Organisation or school | public page | 200 |
| Role | public page: teacher, student, parent, social worker, developer, researcher, other | one of the list |
| A line about you | public page and search | 280 |
| Biography | public page | 4000 |
| Place | public page | 120 |
| Contact address | public page, if you set one; your sign-in address is never shown | an e-mail address |
| Website | public page | an https link |
| Languages | public page | up to the listed codes |
| Picture | public page and the rail | stored as a 256 × 256 image |

Change any of them under **Profile** on [your account page](https://entrosana.app/me). Every change is a line in the record trail without the content, only the field name.

## Your public page

Every account with a name has a public page at `/p/<number>`, also reachable under `/contributors/<name>`. It shows the fields above, your standing, the date you joined, your published modules and the journal entries you mark public.

## Journal

Short entries, up to 2000 characters each, public or private as you choose per entry. Public entries appear on your page and in the Hub's search; private ones are yours alone. You can change or delete any entry later.

> **Note:** The picture is stored with your account and goes with it. Removing it takes one click under Profile.
