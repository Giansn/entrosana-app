# Edit a published module

Every contributor of a module can edit it. Changes are live at once and stamp the module's last update.

## Where

- **Your account page**, block *Your modules*: every module you contribute to, each with **Edit**.
- **The module's card** on the Modules page shows **Edit** when you are one of its contributors.
- **The module page** has an **Edit this module** button for contributors.

## What you can change

| Field | Limit |
|---|---|
| Title | 3 to 120 characters |
| Who it is for | 160 |
| Lede | 300 |
| Text | 4000 |
| Note | 2000, optional |
| State | only an idea, still in development, finished |
| Meta line under the title | 160 |
| Facts | up to 12 pairs of label (60) and value (200) |
| What you get | up to 8 lines |

The area and the slug do not change; ask the team if a module sits in the wrong area.

## Steps

1. Open the editor from one of the places above.
2. Change the fields. Every save writes the module into the catalogue file at once; there is no draft.
3. Set the state when it changes: from *only an idea* to *still in development* when it can be used with care, to *finished* when it is stable.

> **Note:** Each save is a line in the record trail with your account number and the fields that changed, not their content.
