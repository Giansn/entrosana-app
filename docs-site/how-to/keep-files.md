# Keep files in your account

Every account has 400 MB on the Hub's own server in Switzerland: for the files of your modules, for worksheets, for anything you want to link from a proposal.

## Steps

1. Open [your account page](https://entrosana.app/me), block **Files**.
2. Press **Upload**, choose the file and give it a title. Up to 50 MB per file, 200 files per account.
3. Decide per file whether it is **public**. A public file has a link anyone can open; a private one only you.
4. Rename, retitle or delete a file from its row. A deleted file is gone from your account at once and from the backups after 14 days.

## Accepted kinds

`.pdf`, `.png`, `.md`, `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods`, `.odp`, `.zip`.

Other kinds are refused with the list above. A file keeps its ending; renaming may change the name, not the kind.

## Links

A public file's link has the form `https://entrosana.app/api/files/<account>/<file>/<name>`. Use it in a proposal or on a module page. It stops working when the file is deleted or made private; a private file answers 404 to everyone but you.

> **Note:** Files count towards the record trail like everything else: upload, change and deletion are lines with the file number, not the content.
