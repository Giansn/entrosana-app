# entrosana Hub docs

The Hub is the working side of entrosana: where modules for schools are proposed, reviewed, published and kept alive, where you watch the things that must keep running for your work, and where every decision leaves a line in a chain anyone can verify. These docs explain it in plain words, from the first sign-in to the API.

## Where to start

- **New here?** [Create an account](/get-started/create-an-account), then [set up your profile](/get-started/set-up-your-profile) and open [your first project](/get-started/your-first-project).
- **Want to bring a module?** Read [Review and publishing](/concepts/review-and-publishing), then [Propose a module](/how-to/propose-a-module).
- **Something must keep running?** [Services and heartbeats](/concepts/services-and-heartbeats) explains the two directions; [Watch a service](/how-to/watch-a-service) and [Report with a heartbeat](/how-to/report-with-a-heartbeat) are the steps.
- **Building on the Hub?** The [API overview](/reference/api-overview) and [Authentication](/reference/authentication) come first; the rest of the reference is by resource.
- **Data questions?** The [privacy summary](/privacy/summary) and the [retention table](/privacy/retention), with the binding statement on entrosana.com.

## How the docs are organised

| Section | What it answers |
|---|---|
| Get started | The first hour: account, profile, board. |
| Concepts | How things work and why, without steps. |
| How to | One task per page, as numbered steps. |
| API reference | Every endpoint with request, response and limits. |
| Privacy | What is stored, where, for how long, and your rights. |
| Changelog | What changed, by date. |

> **Note:** The Hub is AGPL-3.0. The code, including these docs, is on [GitHub](https://github.com/Giansn/entrosana-app). A development copy of the docs lives at [atrium.entrosana.com/docs](https://atrium.entrosana.com/docs).
